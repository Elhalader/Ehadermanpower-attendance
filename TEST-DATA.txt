TROUBLESHOOTING:
================

PROBLEM: Fields not filling
SOLUTION: Make sure you're copying from this text file or Excel with TAB separators

PROBLEM: Wrong values in fields
SOLUTION: Make sure column order matches (No., Name, Title, Gross Salary, Working Days, OT columns)

PROBLEM: Only first field fills
SOLUTION: Data must be tab-separated. Copy from this file or from Excel (not manually typed with spaces)

PROBLEM: No confirmation dialog for multiple rows
SOLUTION: Make sure you're pasting multiple lines (more than 1). Check for newlines between rows.


COLUMN FORMAT REMINDER:
=======================

Column 1: No. (1, 2, 3, ...)
Column 2: Name (Company/person name)
Column 3: Title (Job title)
Column 4: Gross Salary (Monthly salary in ETB)
Column 5: Working Days (Number of days worked)
Column 6: Normal OT {1.5} (OT hours at 1.5x rate)
Column 7: Night OT {1.75} (OT hours at 1.75x rate)
Column 8: Sunday {2.00} (OT hours at 2.0x rate)
Column 9: Holiday {2.5} (OT hours at 2.5x rate)
Column 10: Performed Task (Optional - work description)

Columns must be TAB-separated (Excel does this automatically)
