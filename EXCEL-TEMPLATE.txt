COLUMN EXPLANATION:
==================

Column A - No.: Sequential number (1, 2, 3, ...)
Column B - Name: Company or contractor name
Column C - Title: Job title (Mason, Carpenter, Electrician, etc.)
Column D - Gross Salary: Monthly salary in ETB
Column E - Working Days: Number of days worked this period
Column F - Normal OT {1.5}: Overtime hours at 1.5x rate
Column G - Night OT {1.75}: Night overtime hours at 1.75x rate
Column H - Sunday {2.00}: Sunday work hours at 2.0x rate
Column I - Holiday {2.5}: Holiday work hours at 2.5x rate
Column J - Performed Task: Description of work done (optional)


IMPORTANT NOTES:
===============

- Use TAB to separate columns (Excel does this automatically when you paste)
- Put 0 (zero) in OT columns if no overtime, don't leave empty
- Working Days is typically 1-30 (days in the month)
- Gross Salary is monthly salary, system auto-calculates hourly rate (÷30)
- Performed Task is optional, can be left empty or filled manually later
- Don't include the header row when pasting to DPR form
